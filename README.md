Uma trilha estruturada e prática para aprender Machine Learning em português. Combina teoria sólida, implementação com código e aplicação prática.

[Consulte o mapa completo de estudos](./index.md)

## Conteúdo

O projeto cobre os principais fundamentos de Machine Learning, progredindo até Deep Learning:

- Fundamentos e estatística
- Dados e pré-processamento
- Regressão e classificação
- Árvores e métodos de ensemble
- Métodos baseados em distância e margem
- Aprendizado não-supervisionado
- Redução de dimensionalidade
- Avaliação e seleção de modelos
- Otimização e treinamento
- Deep Learning

## Estrutura do Projeto

    └── *.ipynb        # Notebooks práticos
