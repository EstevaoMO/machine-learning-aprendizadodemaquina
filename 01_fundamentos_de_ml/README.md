# Fundamentos de Machine Learning

> Introdução aos principais conceitos, paradigmas e processos que fundamentam o Machine Learning.

Este módulo apresenta uma visão geral de Machine Learning antes do estudo dos algoritmos e modelos específicos. O objetivo é construir uma base conceitual para compreender **o que é ML, como ocorre o aprendizado e quais tipos de problemas podemos resolver**.

## 🎯 Objetivos

Ao concluir este módulo, você deverá ser capaz de:

- Explicar o que é Machine Learning e como ele se diferencia de abordagens tradicionais de programação.
- Compreender o processo geral de aprendizado de um modelo.
- Diferenciar os principais paradigmas de aprendizado.·
- Identificar problemas de regressão e classificação.
- Reconhecer diferentes tipos de variáveis e seus papéis em um problema de ML.
